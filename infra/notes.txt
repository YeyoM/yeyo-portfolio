Resources I have for the portfolio:

- S3 bucket called yeyom.tech
- S3 bucket called www.yeyom.tech
- IAM User and policy to deploy the website (CloudFront write access and S3 read and write access)
- Route 53 hosted zone for yeyom.tech
- Certificate for yeyom.tech
- CloudFront distribution for yeyom.tech

Importing the infra

S3 bucket 1

```
terraform import aws_s3_bucket.yeyom_tech yeyom.tech
```

S3 bucket 2

```
terraform import aws_s3_bucket.www_yeyom_tech www.yeyom.tech
```

S3 bucket 3 (terraform state)

```
terraform import aws_s3_bucket.terraform_bucket yeyo-terraform-state-bucket
```

S3 bucket configuration for yeyom.tech

```
terraform import aws_s3_bucket_website_configuration.yeyom_tech yeyom.tech
```

S3 bucket configuration for www.yeyom.tech 

```
terraform import aws_s3_bucket_website_configuration.www_yeyom_tech www.yeyom.tech
